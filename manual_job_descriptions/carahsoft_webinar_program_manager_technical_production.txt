Carahsoft Webinar Program Manager, Technical Production

Location: Remote, United States; EST required
Employment: 1099 Contract

Carahsoft's OpenAI team is seeking an experienced Webinar Program Manager to manage end-to-end operations and technical production of a growing virtual-event program. This program serves government and public-sector audiences for 5+ webinars per week with large-scale virtual audiences.

The Webinar Program Manager will own each webinar from intake through post-event reporting and actions. Responsibilities include scheduling, Gradual or other web-platform configuration, registration operations, speaker preparation, Restream production, attendee support, recordings, replay publication, surveys, and performance reporting.

The Webinar Program Manager will work closely with OpenAI presenters and program leads, Carahsoft teams, platform providers, and other partners. OpenAI subject-matter experts own program content and presentations; the Webinar Program Manager ensures every event is prepared, professionally produced, and repeatable at scale.

This is a hands-on production role. The person must independently operate live events, manage multiple workstreams, enforce production deadlines, and troubleshoot calmly in real time. Ideal candidate is an advanced user of OpenAI products like ChatGPT and Codex.

Responsibilities:
- Program and event operations.
- Gradual and registration management.

- Post-event delivery and reporting.
- Scheduling and platform configuration.
- Speaker preparation.
- Restream production.
- Recording and replay publication.
- Survey operations and performance reporting.
